## 🌟 Philosophy

1. **Work deserves focus.** Group your priorities, clear your tasks, and minimize mental clutter.
2. **Rest deserves permission.** Acknowledge your state without guilt or algorithmic pressure.
3. **Life deserves the remaining time.** Finish what you can today, close the browser, and disconnect.

---

## 🚀 Key Features

- **📋 Structured Projects & Phases**: Break complex workflows into milestones with progress bars and return notes for instant context restoration.
- **🕐 Days Since Tracker**: Factual elapsed days tracker for personal habits and touchpoints (e.g. *Called Mom*, *Read a book*). Zero streaks, zero failure penalties — click 🔄 to reset to today.
- **✉️ Multi-Recipient Emails & Work Widgets**: Draft action checklists for Calls, Emails (multi-ID support with direct `mailto:` launcher), Meetings, and Snoozeable Reminders.
- **📚 Standard Operating Procedures (SOP)**: Quick-reference card grid with a distraction-free Reader Mode.
- **🧠 Footer Stress Meter**: Pixel-perfect manual slider (0–100) for emotional self-awareness.
- **🎮 2-Minute Stress Buster**: Micro-resets (*Swat Mosquito*, *Pop Balloons*, *Smash Distractions with a big hammer*, and *Love Them with custom emojis*) backed by a 15-minute re-entry guard.
- **🌤️ Assisted Weather Widget**: Integrated header badge with GMT presets, city geocoding, and offline resilience.
- **🔒 100% Local-First & Private**: Zero accounts, zero external runtime frameworks, zero trackers. All data stays in your browser's IndexedDB with one-click JSON backup & restore.

## 🛠️ Tech Stack

- **Pure Vanilla Web Standards**: HTML5, CSS3 Custom Properties, Modern JavaScript (ES Modules, async/await).
- **Storage**: Browser-native IndexedDB.
- **Zero Runtime Dependencies**: No npm install, no bundlers, no build step required.

## 💻 Quick Start & Deployment

### Run Locally:
Simply open `index.html` in any modern desktop browser (Chrome, Edge, Firefox, Safari, Brave):
```bash
# Option 1: Direct open
start index.html

# Option 2: Run via any local static server
npx serve .
# or
python -m http.server 8000
```
